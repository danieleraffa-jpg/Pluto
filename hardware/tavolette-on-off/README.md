# Tavolette (on/off)

Dispositivi a trigger semplice, solo on/off — senza controllo continuo come i "raggi".

## Da fare

- [ ] Chiarire con CRAMS quante tavolette servono in un set tipico
- [ ] Scegliere il tipo di interruttore/switch (es. pulsanti accessibili tipo AbleNet, adatti a pazienti con disabilità motoria)
- [ ] Prototipo elettronico: ingresso digitale semplice (GPIO Arduino o ingresso dedicato sull'eobody III)
- [ ] Coordinarsi con il musicista di riferimento CRAMS per il suono associato a ogni tavoletta
