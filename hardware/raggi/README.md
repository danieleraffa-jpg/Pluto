# Raggi

Oggetti impugnabili: il paziente, prendendoli in mano, produce suoni e — in base ai settaggi — può gestire consapevolmente il proprio intervento nella composizione musicale collettiva. Equivalente fisico/maneggiabile dei raggi ultrasonici del Soundbeam.

## Da fare

- [ ] Chiarire con CRAMS che tipo di sensore serve (pressione, piegamento, capacitivo, accelerometro/movimento) per rilevare presa e gesto
- [ ] Definire quanti raggi servono in un set tipico
- [ ] Prototipo elettronico: probabile ingresso analogico sull'eobody III sensorbox, oppure canale dedicato sulla scheda custom
- [ ] Coordinarsi con il musicista di riferimento CRAMS per il mapping suono ↔ gesto
