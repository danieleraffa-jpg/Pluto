# Scheda custom (Arduino Nano 33 IoT)

Circuito realizzato a mano su millefori, basato su Arduino Nano 33 IoT (modulo WiFi/BLE u-blox NINA-W10). Non è un prodotto commerciale: presumibilmente costruita in-house dal responsabile tecnico del progetto Pluto, non più disponibile per chiarimenti.

## Da fare

- [ ] Fotografare il cablaggio da tutti i lati e tracciare a quali pin sono collegati i cavi (visibili: alcuni arancioni/rossi e neri verso l'header di espansione)
- [ ] Collegare via USB e verificare se è già presente un firmware caricato (leggere con Arduino IDE / avrdude prima di sovrascrivere nulla)
- [ ] Se il firmware è leggibile, salvarne un dump qui prima di procedere con eventuali modifiche
- [ ] Capire la funzione della scheda: nodo sensore wireless, bridge verso il software, o altro
- [ ] Documentare pinout e schema una volta chiariti
